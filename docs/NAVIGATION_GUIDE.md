# Navigation Guide - New Features

## For LECTURERS - Accessing New Features

### 1. **Attendance Tracking** 📋
```
Lecturer Sidebar → Attendance
Path: /lecturer/attendance
```
**What to do**:
- Select a module from the dropdown
- Choose date range (optional)
- View student attendance records
- Export to CSV for reports

**Benefits**:
- Track who attended each class
- See attendance patterns
- Generate attendance reports

---

### 2. **Assessment & Grading** 📈
```
Lecturer Sidebar → Assessments
Path: /lecturer/assessments
```
**What to do**:
- Select a module to grade
- View all student scores
- Edit individual grades
- Add new grade entries

**Benefits**:
- Centralized grade management
- Auto-calculated letter grades
- See class performance metrics

---

## For STUDENTS - Accessing New Features

### 1. **Notifications Center** 🔔
```
Student Sidebar → Notifications
Path: /student/notifications
```
**What to do**:
- View all notifications
- Filter unread messages
- Mark as read
- Delete notifications

**Notification Types**:
- 📚 New Content - Course materials uploaded
- 💬 Messages - Direct messages from lecturers/peers
- ⏰ Task Deadline - Upcoming task deadlines
- 🎁 Referral Bonus - You earned referral rewards

---

### 2. **Detailed Progress Analytics** 📊
```
Student Sidebar → Progress → Analytics
Path: /student/progress/analytics
```
**What to do**:
- See overall learning progress percentage
- View completion by module
- Check weekly performance trends
- Track your academic growth

**Key Metrics**:
- Overall Progress %
- Tasks Completed (count)
- Average Score
- Courses Active (count)

---

### 3. **Academic Records & Transcript** 📜
```
Student Sidebar → Records
Path: /student/records
```
**What to do**:
- View your complete academic history
- See grades for each course
- Check your GPA
- Download official transcript (PDF)
- Print your records

**Information Shown**:
- Course Code (e.g., CS101)
- Course Name
- Semester taken
- Credits earned
- Letter Grade
- Numerical Score
- Course Status (Passed/Failed/In Progress)

---

### 4. **Study Groups & Collaboration** 👥
```
Student Sidebar → Study Groups
Path: /student/study-groups
```
**What to do**:
- Create a new study group
- Browse available groups
- Join groups relevant to your courses
- Collaborate with peers

**Group Information**:
- Group name and topic
- Course/module code
- Number of members
- Group description
- Member list

---

## SUPPORT & HELP

### Having trouble uploading notes as a lecturer?
1. Clear browser cache
2. Refresh the page
3. Check internet connection
4. Try a different browser
5. Contact support if persists

### Where to find your grades as a student?
1. Navigate to Student Dashboard
2. Click "Records" in sidebar
3. View your complete transcript
4. Download or print as needed

### How to join a study group?
1. Go to "Study Groups" in sidebar
2. Browse available groups
3. Click "Join" on a group
4. Start collaborating!

### How to track attendance?
**As a Lecturer**:
1. Go to "Attendance" in sidebar
2. Select a module
3. View attendance records
4. Export if needed
